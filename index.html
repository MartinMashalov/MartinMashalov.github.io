agent-fleet

Run thousands of concurrent LLM agent runs on a box that costs six dollars a month.

Most agent frameworks give every agent its own thread or process and fall over somewhere around fifty. But agent work is almost entirely spent waiting on a model API, so the right shape is one asyncio supervisor with a bounded pool. The hard parts are the ones that show up after that: a durable at-least-once queue with leases and idempotency keys so a redelivered step is not executed twice, per-step checkpointing so a killed process resumes mid-run instead of starting over, backpressure that never lets concurrency exceed its cap, and a shared token bucket with circuit breakers so a thousand agents don't stampede one provider. It ships with a deterministic mock model backend, so the benchmark reproduces without an API key or a dollar of spend.

gan-lab

GAN objectives are usually compared with cherry-picked samples. This compares them against ground truth.

On a mixture of Gaussians the true modes are known exactly, which turns mode collapse from something you eyeball into something you measure. Five objectives — non-saturating, LSGAN, WGAN-GP, hinge with spectral normalisation, and R1 — implemented from scratch on a shared trainer and run under identical budgets and seeds, then scored on mode coverage, the rate of samples that land near any true mode, and Wasserstein distance, with error bars across seeds. The metrics are unit-tested against inputs whose answers are known analytically, so the measuring instrument is checked before anything is measured with it.

Sen

A quiet operator for the browser: watch a person do the work once, then do it for them — and repair itself when the page changes.

Sen records how a human moves through a web application, compiles the recording into a section graph, and replays that graph as an automation. The interesting problem is not the recording, it's the decay: selectors rot the moment someone ships a redesign. So a broken xpath is handed to a language model for repair, and when the page has genuinely changed rather than merely moved, a vision-language model looks at it and re-grounds the step. Underneath: a FastAPI service, credential encryption at rest, OAuth and JWT, an async SQLAlchemy store, and a React dashboard where a run is a graph you can watch execute. I also wrote its canvas edge-routing engine, which routes connections around nodes rather than through them.

GridPull

A commercial-lines insurance SaaS, from raw filings to the call list a producer works on Monday morning.

Full stack, end to end: a FastAPI and Postgres backend behind PgBouncer, a React and TypeScript front end, and a 150-worker asyncio pool that streams job progress to the browser over server-sent events. Its first product was a document extraction engine, and that is the part I'd point at — a two-pass PDF reader that scores its own output on field-fill, numeric-parse and date-parse rates, so accuracy is a measured number rather than a reassurance. Running against six families of real documents — invoices, SEC annual reports, 10-K filings, insurance EOBs, purchase orders — it fills 92% of expected fields with a 0% error rate.

AgentAlpha

Agents driving legacy enterprise software that has no API, through the browser, in production.

Some of the systems a business depends on were built before anyone thought to expose an endpoint. AgentAlpha drives them the way a person does — Playwright sessions against management platforms, form filling, document generation — wrapped in the machinery that makes that survivable: a continuous-drain worker loop with a dedicated pool per workload, Redis-backed task state that degrades honestly when a key expires, progress reporting that refuses to say "complete" while a step is still failing, and multi-provider LLM fallback across three vendors so one outage doesn't stop the queue. Deployed with Docker Compose behind nginx.

Research

MSc thesis

Reinforcement learning on diffusion language models

MSc thesis, 2026  ·  trained on SURF Snellius (H100) and rented H200s

Almost every language model you use writes left to right, one token at a time. Diffusion language models don't. They start from a fully masked sequence and denoise all of it in parallel over a fixed number of steps, which makes them far faster in principle — and which breaks most of the reinforcement-learning machinery built for autoregressive models, because there is no clean per-token likelihood to hang a policy gradient on.

My thesis asks whether GRPO — the reinforcement-learning algorithm behind the recent reasoning models — can be made to work on this family, using LoRA adapters and a composite reward, measured on GSM8K, HumanEval and MBPP.

The answer that survived the experiments was not the one I set out to find, and the interesting part of the thesis is the diagnosis rather than the method.

The resultEvery technique I tried made an already RL-tuned DiffuCoder worse, not better — consistently, across seeds and benchmarks.
The causeSignal collapse. After coupled-GRPO post-training the model is saturated, so nearly every sampled group scores identically, the advantage term goes to zero, and the policy gradient has nothing left to push against.
The proofRe-running on an Instruct checkpoint that had never been RL-saturated produced a training signal roughly 2.4× healthier, and the same techniques then behaved as intended — which rules out the methods themselves as the explanation.
Reported honestlyEvery figure carries Wilson confidence intervals. A difference that does not clear them is not claimed as a difference.
